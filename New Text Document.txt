# MarketData — Architecture & Provider Integration Analysis

## 1. هدف

در کنار پروژه فعلی MarketData، قصد داریم یک پروژه آزمایشگاهی کاملاً مستقل با نام MarketDataLab ایجاد کنیم.

مسئولیت پروژه جدید، بررسی منابع جدید اطلاعات بازار، دریافت آزمایشی داده‌های واقعی، پیاده‌سازی دریافت‌کننده‌ها با C# و ذخیره نمونه اطلاعات در فایل JSON است.

پس از تکمیل و تأیید آزمایشگاه، دریافت‌کننده‌های موفق به پروژه اصلی MarketData منتقل خواهند شد.

هدف این تحلیل، شناخت معماری و قراردادهای فعلی پروژه اصلی است تا دریافت‌کننده‌های پروژه آزمایشگاهی از ابتدا به شکلی طراحی شوند که برای انتقال آن‌ها کمترین بازنویسی لازم باشد.

برای هر نوع Provider مشخص کن:

- Base Class احتمالی
- Generic Parameters
- امضای Methodها
- Input Parameters
- Return Types
- CancellationToken
- تنظیمات مورد نیاز
- وابستگی‌های Constructor

- نحوه تشخیص No Data

به‌خصوص بررسی کن که دریافت‌کننده‌های فعلی از چه قراردادهایی استفاده می‌کنند.

برای مثال:

- Candle Provider
- Instrument Provider
- Catalog Provider

این نام‌ها صرفاً مثال هستند. نام‌های واقعی موجود در پروژه استخراج شوند.

مشخص کن آیا Providerها Interface مشترک دارند یا هر نوع داده قرارداد متفاوتی دارد.

کد کامل Interfaceها و Base Classهای مرتبط را در خروجی قرار بده.

## 13. Adding a New Provider

این بخش باید به‌صورت یک دستورالعمل واقعی و مرحله‌به‌مرحله ارائه شود.

فرض کن می‌خواهیم یک Provider جدید برای دریافت اطلاعات اقتصادی از سایت Federal Reserve ایجاد کنیم.

بدون پیاده‌سازی واقعی و بدون تغییر پروژه، توضیح بده:

- چه فایل‌هایی باید ایجاد شوند؟
- هر فایل در کدام پروژه و فولدر قرار می‌گیرد؟
- نام پیشنهادی کلاس‌ها بر اساس Naming Convention فعلی چیست؟
- کدام Interface باید پیاده‌سازی شود؟
- چه Base Classهایی قابل استفاده هستند؟
- چه DTOهایی قابل استفاده هستند؟
- چه Dependencyهایی لازم هستند؟
- Configuration چگونه تعریف می‌شود؟
- Provider چگونه ثبت می‌شود؟
- Job چگونه آن را فراخوانی خواهد کرد؟
- خروجی Provider چه ساختاری دارد؟
- آیا برای داده غیرکندلی نیازمند توسعه قرارداد موجود هستیم؟
- چه تغییراتی در آینده در پروژه اصلی لازم خواهند بود؟

دو سناریو بررسی شوند:

A. اضافه کردن یک Provider جدید برای Candle و OHLCV.

B. اضافه کردن یک Provider جدید برای داده اقتصادی Time Series غیرکندلی.
